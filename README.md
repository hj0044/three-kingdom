# 삼국지 · 황건의 봄

모바일 세로 화면용 싱글플레이 전략 게임 개발 시험판. 184년을 배경으로 군주 전략과 장수의 삶을 연결한다. 정적 HTML/CSS/ES modules로 구성하며 런타임 유료 API나 서버 데이터베이스가 필요하지 않다.

## 실행

`python3 -m http.server 8000 --directory dist` 후 브라우저에서 http://localhost:8000 접속. ES modules이므로 index.html 파일 직접 열기 대신 HTTP로 제공한다. 호스팅 배포 디렉터리는 `dist`다.

## 검증

Node 20 이상에서 `npm test` 및 `npm run check`. 외부 패키지 설치 불필요.

## 현재 상태

도시 명령, 시간 진행, 관직·임지 권한, 동일 주둔지 교류·현령 임명, 출진·자동 전투, 저장 파일 교환이 구현되어 있다. 184년의 출발 관직·주요 관계는 기록을 기준으로 하되, 지도·병력·능력치는 게임용 압축이다. 세부 기준은 [docs/HISTORY.md](docs/HISTORY.md)에 있다. 재야·독립·전사·포로·외교와 목표 기반 NPC는 후속 개발이다. 상세 확정 사항과 완료 기준은 [docs/DESIGN.md](docs/DESIGN.md).

기기 저장은 사이트별이므로 다른 호스팅 주소로 이동할 때 JSON 파일로 이전해야 한다. 클라우드 동기화는 없다. 개인정보나 접속 분석을 수집하지 않는다. 코에이의 코드·미술·음악·데이터를 사용하지 않는다.


## v0.4 업데이트

지도 11개 거점, 활동 인물 11명과 후대 등장 후보 3명으로 확장했습니다. 재야 인재 등용, NPC의 자율 등용, 빈 도시 태수 임명을 구현했습니다. 이전 저장은 자동 전환됩니다.

## v0.5 UI·UX 개선

새 캠페인은 선택한 인물의 실제 임지에서 시작합니다. 인물 선택 전에 능력·관직·초기 목표를 확인하고, 천하 탭에서 플레이어의 임지·자원·다음 목표를 먼저 봅니다. 인물 동향은 동료와 적 세력으로 걸러볼 수 있고, 도시 명령에는 예상 효과를 표시합니다. 저장을 이어갈 때와 파일을 불러올 때도 지도 선택이 플레이어 임지에 맞춰집니다.


## v0.5.1 도시·인물 UX

도시 선택 탭에 임지·직할·아군 구분을 표시하고, 명령이 잠긴 이유를 화면에 안내합니다. 임관 후보는 정치력 순으로 보이며, 인물 탭에서도 빈 관할 도시의 태수를 임관할 수 있습니다. 등용 가능 인재·자금 부족·세력 인원 한도를 안내하고, 등용 성공과 실패 결과를 즉시 보여줍니다.

## v0.6 자원·도시 경제

도시별 인구가 세수·군량 소비·징병의 기반이 됩니다. 매일 세금과 병력 급료, 농업 생산과 민간·군대 군량 소비가 반영되고, 군량은 인구와 농업에 따른 저장 한도에서 넘치지 않습니다. 주간 농업 방침은 농지와 인구 성장을 돕고, 군비 방침은 자금과 인구를 써 병력을 보강합니다. 태수의 정치력은 세수에 반영됩니다. 내정 화면은 주간 자금·군량 예상 흐름과 저장 한도를 보여줍니다. NPC 세력도 같은 경제 규칙을 쓰며 지출 비축금을 남겨 둡니다.

v0.4 저장은 기존 날짜·도시 자원·명령을 보존하면서 인구를 추가해 자동 전환됩니다. 인구와 자원 수치는 역사 통계를 재현하지 않는 게임용 추상값입니다.
