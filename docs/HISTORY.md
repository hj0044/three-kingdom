# 184년 역사 기반 데이터 원칙

이 문서는 게임이 **역사 기록**과 **게임용 압축·각색**을 구분하기 위한 기준이다. 수치 능력치와 도시 자원은 역사 사실이 아니다.

## 기록에서 채택한 출발점

- 184년 황건의 난은 장각이 주도했고, 장보·장량이 함께 언급된다.
- 후한 조정은 황보숭·주준·노식 등을 중랑장으로 보내 토벌했다. 노식은 거록 방면에서 장각을 상대하는 전선으로 배치한다.
- 하진은 대장군으로 조정의 군사권을 가진 인물로 표현한다.
- 조조는 황건의 난 시기에 기병교위로 임명된 경력을 출발 관직으로 쓴다.
- 유비는 황건 토벌을 위한 의병을 모았고, 관우는 유비의 측근으로 전해진다. 게임의 탁현 주둔·초기 병력은 이 사실을 바탕으로 한 각색이다.

## 확인 기준

1. `후한서` 영제기·황보숭주준열전·노식열전
2. `삼국지` 위서 무제기, 촉서 선주전·관우전
3. 사마광, `자치통감` 한기 영제 중평 원년

## 게임용 압축

- 지도는 낙양·탁현·진류·거록·영천·광종·완·양양의 **핵심 전선 8개**만 쓰며, 행정구역·거리·병력·점유 상태를 실제 지도 전체처럼 재현하지 않는다.
- 한 조정군은 하나의 플레이 단위다. 실제 후한의 중앙 지휘와 지방 행정의 복잡한 관계를 대장군·지방관·임지의 세 단계로 단순화한다.
- 장각·장보·장량은 각각의 거점을 가진 황건 지휘자로 표현한다. 역사적 영향권·부대의 정확한 경계는 후속 데이터 확장에서 보완한다.
- 유비와 관우의 초기 관계는 전통적 기록을 게임 시작 관계로 사용한다. 친밀도와 능력치는 게임 수치다.

## 데이터 적용 규칙

출생·사망·활동 시기, 당시 관직, 주요 소속은 기록으로 확인한 뒤 `people` 데이터에 반영한다. 불확실하거나 설화성이 강한 관계는 `traditional` 또는 게임 각색으로 표시한다. 인물·도시 확대 시 출처와 적용 연도를 이 문서에 추가한다.
