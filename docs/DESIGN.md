- 유료 개발 도구·API·서버가 필수인 구조 금지. 기본 실행은 정적 파일과 브라우저 계산. 호스팅 무료 한도는 배포 시 검증. 사용자의 ChatGPT 요금이나 플랫폼 한도까지 무료 보장하지 않음.
- 저장은 기기 내부와 JSON 내보내기·불러오기. 기존 저장은 명시적 새 게임·가져오기 외에 덮어쓰지 않음. 잘못된 파일은 현재 상태 변경 전에 거부.
- 코에이 게임의 독점 이미지·음악·코드·수치표를 복제하지 않음.

## v0.1 실제 구현 범위

개발 시험판: 8개 도시·8명 인물, 모든 인물 선택, 일 단위 명령 지속, 도시 4종 명령, 주간 위임, 1일 1회 양방향 교류, 공적 기반 태수 승진, 출진·이동·보급 출발지 검사·자동 전투, 적 세력의 정기 습격과 병력 강화, 사건 확인·동원 선택, 시간 중단, 자동 저장·파일 교환. 계승 함수와 선택 화면은 사망 상태를 지원하지만 자연 사망/전사 발생기는 미구현.

수치와 초기 세력·지명 위치·임관 관계는 명시적인 시험용 각색. v0.1 데이터를 역사적 사실로 취급하지 않는다. ‘의리’는 성격 수치이며 세력 충성도는 후속 분리한다. 통솔 이외 능력·야망·의리는 데이터 기반만 마련됐고 행동 효과는 아직 없다. 도시 명령은 현 버전 장수에게 소속 도시 전역에서 허용하는 임시 건의 모델이다.

## 다음 개발 순서와 완료 조건

1. 역사 데이터: 184년 지명·세력·관직·활동 인물을 공개 출처로 검증. 한 조정 아래 지휘권·지방 지배를 분리. 모든 등록 인물의 소속/관계/활동 가능 연도 검증.
2. 권한·신분: 인물 위치와 근무 도시, 군주 임명·태수 관할, 재야·임관·전직·독립·멸망·포로. 현재 화면이 부여하지 않은 권한은 엔진에서도 거부.
3. 전쟁: 연결 경로 다중 이동, 장수 편성, 수송 위임, 사전 위험 예측, 포로·전사·귀환 시간·전투 보고. 부대·군량 중복 반영 금지. 전투로 사망하면 계승을 연결.
4. NPC: 목표·성격·관계로 내정·등용·외교·전쟁 결정. 시간 기반 결정론과 동등한 자원 규칙. 공짜 병력 증원·정기 고정 습격은 폐기.
5. 역사 사건: 조건 검사와 중복 방지, 같은 날 사건 큐, 중요한 선택 후 남은 일수 명시적 재개.
6. 콘텐츠·밸런스: 고증 지도 확대, 다채로운 목표, 선택의 원인·결과, 30/90/365일 검증. 기술 안정성과 실제 재미를 각각 판정.
